# Portfolio Case Study: RetailPulse

## Scenario
A fictional online retailer needs clear reporting on sales, profit, product mix, regions and repeat purchasing.

## Objective
Build an analytics workflow and interactive dashboard that turns transaction-level data into business KPIs and descriptive insights.

## Method
1. Generate a reproducible synthetic dataset of 3,000 order records.
2. Validate and transform dates, prices, discounts, quantity and order status.
3. Calculate gross sales, net sales, recognised revenue, gross profit and margin.
4. Analyse month, category, region, product, order status and customer purchase frequency.
5. Present the results in a filterable Streamlit dashboard and retain SQL examples.

## Financial rule
Only Delivered orders contribute recognised revenue and cost. All statuses remain visible in operational order counts.

## Limitations
All data is synthetic. The patterns are useful for demonstrating methods but do not describe a real retailer. Tax, refunds, inventory and marketing spend are not modelled.
